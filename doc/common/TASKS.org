| ~/etc/qmail/~                  | qmail control files (symlinked from ~/var/lib/qmail/control/~) |
| ~/var/lib/qmail/~              | qmail home (Debian convention; ~/var/qmail/~ in upstream)      |
| ~/var/lib/qmail/queue/~        | Mail queue                                                     |
| ~/var/lib/qmail/bin/~          | qmail binaries                                                 |
| ~/home/vpopmail/~              | vpopmail home                                                  |
| ~/home/vpopmail/domains/~      | Virtual domain files                                           |
| ~/etc/qmail/domainkeys/~       | DKIM signing keys                                              |
| ~/etc/sv/~ or ~/etc/services/~ | daemontools service directories                                |
