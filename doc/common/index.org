This is the *architecture-neutral* documentation core for the DSMR mail stack.
It is carried, unchanged, by every stack metapackage (the full
=dsmr-email-encabulator= profile, and any narrower profile such as a future
=dsmr-mta-only=). Profile-specific architecture and runbooks live in each
metapackage's own =index.org= one level up, which links here.

* The base layer
Every DSMR profile is built on the same qmail foundation, layered bottom-up:

: fehqlibs-dev -> libsrs2 -> ucspi-ssl -> qmail (+ qmail-uids-gids)

What a given profile adds on top of this base (vpopmail, dovecot, system-first
routing, …) is described by that profile's own documentation.
