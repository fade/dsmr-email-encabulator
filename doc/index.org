Documentation root for the *full* DSMR stack as installed by
=dsmr-email-encabulator= — the "everything" profile: qmail + vpopmail virtual
users + dovecot IMAP, with system-first recipient routing on hybrid domains.

The architecture-neutral core (base qmail layer, dev log, research, DKIM,
packaging workflow) is in [[file:common/index.org][common/index.org]] and is shared with every stack
profile. This file documents what the full profile adds on top.

* Profile architecture
On top of the common base layer (=fehqlibs -> libsrs2 -> ucspi-ssl -> qmail=),
the full profile adds:

: + vpopmail (PostgreSQL virtual users) + dovecot-vpopmail (IMAP)
: + dsmr-qmail-run (supervised services)
: + dsmr-checkpassword-dovecot (system + virtual SMTP-AUTH)
: + dsmr-localfirst (system-first recipient routing on hybrid domains)

A texinfo reference manual is shipped: =dsmr-email-encabulator.info=
(source =dsmr-email-encabulator.texi=).
